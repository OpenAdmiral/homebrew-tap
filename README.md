# OpenAdmiral Homebrew tap

```sh
brew install --cask openadmiral/tap/openadmiral
```

Installs [OpenAdmiral](https://openadmiral.com), mission control for your Claude Code
sessions (macOS 13 or later, Apple Silicon and Intel). The app updates itself; this
cask follows each release within a few hours.

Then add the plugin in any Claude Code session:

```
/plugin marketplace add OpenAdmiral/openadmiral
/plugin install openadmiral@openadmiral
```
